The space

An uneven bay, not a square one

The window wall is 102" across with a 79" window centered in it. The two return walls that box in the nook aren't the same length — one is 4⅛" deeper than the other — so the footprint is a shallow trapezoid, not a rectangle.

Shared across both plans

The bench under the window

The sill sits 31.5" up, which sets the ceiling on how tall the seat can be. A 19" seat leaves about 12" of reveal above the cushion before hitting the glass — enough for a cushion and a couple of throw pillows without crowding the window.

Option 1

Plan A — keep the litter box, build it flexible

The deeper return wall (40¼") keeps the litter cabinet, but built as a standard-depth carcass with adjustable shelf pins inside — so it can be repurposed later without tearing anything out.

40¼" wall — tower built 22"W × 24"D × 81"H

  • Only using 24" of the available 40¼" depth — the remaining ~16" behind the cabinet can hold a slim pull-out for litter mats or supplies rather than sitting empty.

When the litter box eventually goes, the door comes off, shelf pins drop in at the same spacing as the tower above, and the whole thing reads as one continuous bookcase — no rebuild.

Option 2

Plan B — no litter box, symmetrical shelving

If the litter box moves out of the room, both return walls become matching open bookcases. Since they're 4" different in depth, both towers get built to the shallower measurement (36⅛") for a clean, symmetrical front — the extra depth on the deeper side just gets furred in behind the cabinet back.

Before building the towers

Open decision: relocate the litter box?

The bench across the window wall is identical in both plans, so that piece can be built first regardless. The two side towers are where the plans diverge — worth deciding before cutting the return-wall cabinets.

Note: if going with Plan A, confirm the cabinet's interior clear opening against the actual litter box footprint before finalizing the carcass width — leave a little slack for a different box shape down the road.
